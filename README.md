# quattle Homebrew tap

    brew install quattle/tap/quattle

Installs the quattle command line: `quattle ls`, `quattle put`, `quattle sync`, `quattle serve`, `quattle mcp` and the rest, plus `git-annex-remote-quattle`. Runs on Homebrew's Python; nothing else to install.

Set your tokens once per shell, or in your shell profile:

    export QUATTLE_READ_TOKEN="..."
    export QUATTLE_WRITE_TOKEN="..."

Upgrade with `brew upgrade quattle`. Docs: https://quattle.app/docs
